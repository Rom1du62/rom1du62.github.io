Etude sur l'alimentation dans le monde

Objectif: Réaliser une première analyse de données en Python à l’aide de Pandas, Numpy et Matplotlib

Contexte

Il s’agit de mon premier projet nécessitant l’utilisation d’un notebook Python pour analyser des données. Ce travail m’a permis de découvrir les bibliothèques plébiscitées par la communauté des Data Analysts, notamment Pandas, Numpy et Matplotlib. J’ai pu constater la puissance de Python et la rapidité avec laquelle il permet de manipuler et visualiser une grande quantité de données.

Démarche

  • Importation et analyse des différents fichiers
  • Manipulation des données
  • Choix des graphiques pertinents
  • Support de présentation

Outils utilisés

Python (Pandas, Numpy, Matplotlib)

Compétences acquises

  • Mise en place d'un environnement de travail sous Jupyter Notebook
  • Initiation à Python
  • Commandes de base Pandas
  • Commandes de base Numpy
  • Commandes de base Matplotlib
