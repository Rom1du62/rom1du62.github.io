Mise en place d'une base de données dans l'immobilier

Objectif : Importer des données issues de la DVF dans une base de données et lancer des requêtes.

Contexte

Etablir un modèle conceptuel de données, l'importer dans SQLite, intégrer des données issues de la DVF et établir des requêtes pour contrôler les résultats

Démarche

  • Mise à jour des données sous Excel
  • Création de différents type de graphiques.
  • Choix des graphiques pertinant.
  • Support de présentation à destination du comité de direction.

Outils utilisés

SQLite, PowerArchitects, Excel.

Compétences acquises

  • Mise en place d'un Modèle de données.
  • Apprentissage des formes normales.
  • Utiliser le language SQL.
